# 流程记忆（Flow Memory）

流程记忆是一个面向 Codex 的本机插件，把长对话中的主步骤、次级步骤、注意事项、进度、输入产出和相关文件整理成当前对话专属的右侧流程图谱。

它适合流程较长、需要反复补充要求、容易遗漏步骤，或者希望把一次工作整理成可复用 SOP 的场景。

## 主要功能

- 按对话隔离流程图谱，切换对话时读取对应数据。
- 以“主步骤 → 次级步骤 → 注意事项”展示复杂工作。
- 支持状态、进度、手动编辑、拖拽整理、撤销和恢复原始顺序。
- 保存少量关键对话依据，不复制完整聊天记录。
- 记录输入、产出、格式规则和跨项目文件来源。
- 把 PDF、Word、Excel、PowerPoint、Markdown 等相关文件放到对应步骤下，并从面板直接打开原文件。
- 原始流程与整理视图分开，调整展示不会破坏原始流程逻辑。

完整设计、功能细节、安全边界和当前限制请阅读 [使用说明.md](./使用说明.md)。

## 环境要求

- Node.js 18 或更高版本
- 支持本机 stdio MCP 插件的 Codex 环境

## 安装依赖与测试

```powershell
pnpm install --frozen-lockfile
pnpm test
```

也可以使用 npm：

```powershell
npm install
npm test
```

## 加载插件

仓库根目录已经包含：

- `.codex-plugin/plugin.json`：插件入口
- `.mcp.json`：Codex 使用的本机 MCP 配置
- `skills/capture-workflow/`：流程记录规则
- `server.js`：MCP 服务与开发预览入口

将本仓库作为本机插件加载后，Codex 会通过 stdio 启动服务。日常使用不需要手动启动网页服务器，也不需要长期占用端口。

具体的 Codex 插件加载入口可能随应用版本变化，请以当前 Codex 的插件界面为准。

## 隐私与公开仓库

本仓库只应提交代码、测试、配置和说明文档。以下内容已通过 `.gitignore` 排除：

- `data/state.json`：本机运行状态，可能包含少量对话摘录、文件名和绝对路径。
- `.test-tmp/`：测试缓存和 Node 编译缓存。
- `node_modules/`：本机安装的依赖。
- `.env*`、日志和编辑器配置等本机文件。

插件不会把 `data/state.json` 当作发布内容。其他电脑安装后会建立自己的独立运行数据，不会继承仓库作者的私人记录。

提交前建议执行：

```powershell
git status --short
git check-ignore -v data/state.json .test-tmp node_modules
```

如果 `data/state.json` 曾经被 Git 跟踪，仅添加 `.gitignore` 不会自动移除历史记录；需要先从 Git 索引中移除，并在公开前检查提交历史。

## 安全说明

- 本地预览仅监听回环地址 `127.0.0.1`。
- 相关文件必须是已经存在的普通文件，并通过文档扩展名和路径过滤。
- 从图谱移除文件记录不会删除电脑上的原始文件。
- 界面输出对动态文字进行 HTML 转义。
- 不应在流程摘录中保存密码、令牌、身份证号等敏感信息。
